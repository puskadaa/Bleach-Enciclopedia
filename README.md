# BLEACH — Enciclopédia das Almas

Site estático, responsivo e navegável por abas. Abra a pasta no VS Code e rode **Open with Live Server** no `index.html`, ou sirva a pasta com qualquer servidor estático.

- `js/data.js`: banco de dados local com personagens, organizações, Zanpakutō, Shikai, Bankai, arcos, termos, autor e fontes.
- `js/app.js`: rotas por hash, busca global, filtros, fichas detalhadas e alternância entre arte de anime e mangá.
- `css/style.css`: direção visual inspirada no mangá — preto, branco, laranja, retícula, cortes diagonais e tipografia editorial.
- `assets/`: imagens otimizadas em WebP e fontes locais em WOFF2.

Contém spoilers do mangá e do anime. Projeto de fã, sem fins lucrativos.
